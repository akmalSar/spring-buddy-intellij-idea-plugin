Why It Is Unique

Most tools see syntax. Spring Buddy models Spring consequences.

The plugin focuses on bugs caused by framework behavior that is legal Java but wrong Spring: proxy bypasses, transaction boundaries, lifecycle timing, repository semantics, lazy loading, test false positives, and style drift.

Spring proxy awareness

Flags private, final, static, self-invoked, CGLIB-blocked, constructor-triggered, async, and interface transaction patterns that Spring AOP cannot apply.

Runtime risk, editor timing

Surfaces production-class issues while the file is open: missing transactions, ignored annotations, broken Mockito calls, and lifecycle traps.

Developer-safe fixes

Add @Transactional, remove final, add EnumType.STRING, add auditing listeners, move lifecycle work, and convert unsafe assertions.

Transaction inlay hints

Shows inline propagation behavior: starts transaction, starts new transaction, nested transaction, or ignored self-invocation.

Inter-procedural taint analysis

DataFlow engine tracks detached entities through aliases, Optional unwraps, casts, ternaries, for-each loops, stream lambdas, and private helpers — finding Ghost Saves and N+1 patterns.

Test ecosystem support

Understands AssertJ, Mockito, MockMvc, ArchUnit, and helper-method assertion patterns instead of applying a single naive assertion rule.

Bundled inspection pass

Runs Spring Buddy after large refactors, generated code changes, or AI-assisted rewrites to catch hidden framework regressions.

Concrete Example

It catches valid Java that Spring will not execute the way it looks.

A same-class call to a transactional method looks correct in Java, but bypasses the Spring proxy. Final classes, private methods, @PostConstruct, and missing @Transactional boundaries fail for the same reason.

Feedback Types

Different problems need different IDE feedback.

Spring Buddy uses errors for definite runtime breakage, warnings for likely design risks, quick fixes for safe edits, inlay hints for runtime explanation, and runner actions for broad sweeps.

Errors

Mark definite runtime breakage: ignored proxy advice, @Transactional on private/final/static methods, self-invocation, readOnly transactions with writes, swallowed exceptions, unclosed Streams, SQL injection via @Query concatenation, and read-only entity mutation.

Warnings

Flag likely design risks and style drift: import ordering, modifier placement, method visibility, test naming, TODO/FIXME without tickets, collection return nulls, @RequestMapping without HTTP method, fixedRate without initialDelay, and Ghost Save.

Quick Fixes

Add @Transactional, choose REQUIRES_NEW, remove final, add EnumType.STRING, add auditing listeners, add mappedBy, wrap Stream in try-with-resources, convert to contextual orElseThrow, or replace string concatenation with parameter placeholders.

Inlay Hints

Show transaction behavior inline: starts transaction, starts new transaction, suspends transaction, nested transaction, or ignored boundary.

Inspection Runner

Runs the Spring Buddy inspection profile from a context menu action against the current scope.

After Big Refactors

Especially useful after broad AI-assisted rewrites.

Large refactors can keep Java compiling while silently changing Spring behavior. Spring Buddy gives you a second pass focused on the things compilers and ordinary linters miss.

Proxy Semantics

Catches final classes, final/private/static advised methods, self-invocation, and ignored @PostConstruct transactions introduced during cleanup.

Repository Semantics

Finds @Modifying without @Transactional, derived query explosions, Optional.get() without context, and projection methods that force full entity loads.

Persistence Drift

Flags enum ordinal mappings, missing auditing listeners, @OneToMany surprises, N+1 lazy access, OSIV risks, and Ghost Saves from detached entity mutations introduced by AI rewrites.

Test Behavior

Recognizes real assertions after test rewrites and catches @MockBean context fragmentation that makes suites slower after refactors.

Concurrency Regressions

Highlights singleton mutable state, shared caches, @Async writes, and suggests final, volatile, AtomicReference, or ConcurrentHashMap where appropriate.

Fast Safety Gate

Run the bundled inspection profile after a migration or generated patch to surface hidden framework bugs before review. DataFlow engine catches cross-method persistence issues.

A compiling AI refactor is not necessarily a correct Spring refactor. Spring Buddy checks the framework contracts the compiler cannot see.
