Reports Mockito stubbing or verification calls that mix argument matchers (any(), eq(), anyInt(), ...) with raw values: 
when(service.lookup(any(), 42)).thenReturn(...);   // raw 42 must be eq(42)
verify(service).save(eq(user), "ADMIN");           // raw "ADMIN" must be eq("ADMIN")

Mockito requires that either all arguments use matchers or none do. Mixing them throws InvalidUseOfMatchersException at runtime.

The quick-fix wraps raw arguments with eq(...), preserving the qualifier used by the existing matcher when calls are qualified.
