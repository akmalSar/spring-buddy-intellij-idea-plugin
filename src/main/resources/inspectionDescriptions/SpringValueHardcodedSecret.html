Reports @Value annotations on fields whose name suggests a secret (password, secret, token, apiKey, etc.) when the value is a hardcoded string literal instead of a property placeholder.

Hardcoded credentials are committed to source control and leaked to every developer, CI log, and build artifact. Replace the literal with a placeholder such as ${db.password} or #{systemProperties['secret']} and store the actual value in environment variables, a secret manager, or an external properties file that is never committed.
