Reports @Async methods (and classes annotated with @Async) that do not specify an explicit executor attribute.

Without a custom executor Spring falls back to SimpleAsyncTaskExecutor, which creates a new thread for every single task. Under load this exhausts memory and eventually crashes the JVM with OutOfMemoryError. Specify @Async("taskExecutor") and provide a bounded ThreadPoolTaskExecutor bean, or implement AsyncConfigurer to define a default executor.
