Reports mutations of detached JPA entities that will be silently ignored because there is no active Hibernate session to flush the changes to the database (a "Ghost Save").

An entity becomes detached when it is fetched from a Spring Data repository or EntityManager outside an active @Transactional context. Any setter or mutator called on such an entity will appear to succeed at runtime but will never be persisted.

Examples of code that triggers this inspection

Basic ghost save


// No @Transactional — entity is detached immediately after fetch
public void updateName(Long id, String name) {
    User user = userRepository.findById(id).orElseThrow();
    user.setName(name);   // ← flagged: change will not be persisted
}

Ghost save through a helper method (inter-procedural)


public void process(Long id) {
    User user = userRepository.findById(id).orElseThrow();
    applyDefaults(user);   // ← flagged: taint follows into the callee
}

private void applyDefaults(User user) {
    user.setStatus("ACTIVE");   // ← also flagged
}

Ghost save through an alias


public void process(Long id) {
    User original = userRepository.findById(id).orElseThrow();
    User alias    = original;     // alias is also detached
    alias.setName("Bob");         // ← flagged
}

How to fix

The recommended fix is to annotate the enclosing method (or its containing class) with @Transactional. This ensures the entity remains in the managed state for the duration of the method, and Hibernate will automatically flush any changes at the end of the transaction. 


@Transactional   // ← added
public void updateName(Long id, String name) {
    User user = userRepository.findById(id).orElseThrow();
    user.setName(name);   // now persisted automatically
}

Alternatively, call repository.save(entity) explicitly after all mutations — but prefer @Transactional as it is less error-prone and covers all mutations in the method body.

Suppression

If you have intentionally fetched a detached entity and do not want the changes persisted (e.g. for in-memory transformation only), suppress the warning with: 


@SuppressWarnings("SpringGhostSave")
public void transformOnly(Long id) {
    User user = userRepository.findById(id).orElseThrow();
    user.setName(enrichName(user.getName()));   // intentionally not persisted
    sendNotification(user);
}
