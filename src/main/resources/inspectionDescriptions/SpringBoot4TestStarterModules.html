Reports build files that combine spring-boot-starter-test with a technology starter but lack the matching modular test starter (for example spring-boot-starter-webmvc-test or spring-boot-starter-data-jpa-test).

Spring Boot 4 splits test support into per-technology test starters. Slice tests that relied on the monolithic starter's transitive dependencies need the dedicated module after the upgrade.

Add the matching spring-boot-starter-<technology>-test dependency.
