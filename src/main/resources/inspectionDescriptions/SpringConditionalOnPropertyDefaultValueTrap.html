@ConditionalOnProperty matchIfMissing contradicts @Value default

Reports cases where @ConditionalOnProperty(matchIfMissing = true) on a @Bean method is paired with @Value("${property:default}") on a field referencing the same property with a conflicting default. If the property is missing, the bean is created due to matchIfMissing, but the injected value reflects a disabled state — creating a running service that thinks the feature is turned off.
