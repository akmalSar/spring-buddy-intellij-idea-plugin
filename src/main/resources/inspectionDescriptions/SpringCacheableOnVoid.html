Reports {@code @Cacheable} or {@code @CachePut} annotations on {@code void} methods.

Spring Cache stores the return value of a method in the cache. When the method returns {@code void} there is nothing to store, so the annotation is silently ignored at runtime. The developer may believe caching is active when it is not, leading to unnecessary database load.

Fix: Remove the annotation, or change the method to return the cached value if the intent was truly to cache data.
