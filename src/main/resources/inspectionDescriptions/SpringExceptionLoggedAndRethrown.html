Reports catch blocks that log an exception via SLF4J (or Lombok's @Slf4j-generated log field) and then rethrow the same exception variable.

This is a classic double-logging anti-pattern: the exception will be logged again by the caller or the global error handler, producing duplicate stack traces and noisy logs. 

catch (IOException ex) {
    log.error("oops", ex); // redundant
    throw ex;
}

Quick-fix removes the redundant log statement. Either log or rethrow — not both.
