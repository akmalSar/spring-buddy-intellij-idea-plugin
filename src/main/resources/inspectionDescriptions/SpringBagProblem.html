@OneToMany / @ManyToMany with List causes bag semantics

Reports JPA @OneToMany or @ManyToMany fields typed as java.util.List. In Hibernate, a List allowed to contain duplicates is treated as a "Bag", causing Hibernate to delete every row in the join table and re-insert all of them on every collection change. Use java.util.Set instead — Hibernate can then issue a single INSERT or DELETE statement for incremental updates.
