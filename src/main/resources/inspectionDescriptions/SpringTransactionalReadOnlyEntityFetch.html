Read-only transaction fetches entities

Reports read-only transactional methods that appear to return managed entity types. Hibernate may still create snapshots for dirty checking, wasting memory and CPU. Prefer DTO projections or read models for read-only use cases.

Not reported when Hibernate is on the classpath and spring.jpa.open-in-view is set to false. In that case Spring's HibernateJpaDialect runs each read-only transaction on a transaction-local session and calls setDefaultReadOnly(true), so loaded entities keep no snapshot.
