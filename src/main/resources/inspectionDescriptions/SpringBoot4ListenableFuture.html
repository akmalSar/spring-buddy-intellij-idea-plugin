Reports usages of Spring's ListenableFuture API (ListenableFuture, SettableListenableFuture, ListenableFutureCallback, AsyncResult), removed in Spring Framework 7 (Spring Boot 4).

Spring Framework 7 dropped the deprecated ListenableFuture family. APIs now use CompletableFuture.

Replace ListenableFuture with CompletableFuture (supported since Spring 6), for example CompletableFuture.completedFuture(value) and thenApply/thenAccept chains.
