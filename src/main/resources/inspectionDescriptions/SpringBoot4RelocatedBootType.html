Reports Spring Boot types that were relocated by the Boot 4 modularisation, for example org.springframework.boot.autoconfigure.domain.EntityScan → org.springframework.boot.persistence.autoconfigure.EntityScan, @WebMvcTest → org.springframework.boot.webmvc.test.autoconfigure.WebMvcTest, @DataJpaTest → org.springframework.boot.data.jpa.test.autoconfigure.DataJpaTest and TestRestTemplate → org.springframework.boot.resttestclient.TestRestTemplate, @PropertyMapping → org.springframework.boot.test.context.PropertyMapping, BootstrapRegistry and related classes → org.springframework.boot.bootstrap and the deprecated org.springframework.boot.env.EnvironmentPostProcessor → org.springframework.boot.EnvironmentPostProcessor (reported as a warning).

Spring Boot 4 splits the monolithic auto-configuration into per-technology modules, moving most types to dedicated packages such as org.springframework.boot.webmvc.autoconfigure.

Quick fix updates the import or fully-qualified reference to the new package when the simple name is unchanged. For @AutoConfigureMockMvc the HtmlUnit flags webClientEnabled/webDriverEnabled are moved into htmlUnit = @HtmlUnit(webClient = ..., webDriver = ...).
