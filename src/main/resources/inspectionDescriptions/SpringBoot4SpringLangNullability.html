Reports org.springframework.lang.Nullable / NonNull / NonNullApi / NonNullFields, deprecated in Spring Framework 7 (Spring Boot 4) in favour of JSpecify.

Spring Framework 7 now ships JSpecify annotations, which provide a specification, better Kotlin integration and tooling support. The Spring annotations remain deprecated during the migration.

Replace org.springframework.lang.Nullable with org.jspecify.annotations.Nullable (quick fix available). For package-level NonNullApi/NonNullFields switch the package to @NullMarked manually — it changes the semantics of the whole package.
