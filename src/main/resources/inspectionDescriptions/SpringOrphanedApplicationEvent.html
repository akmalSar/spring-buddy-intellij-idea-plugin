Reports Spring application events that have no matching listeners and listeners whose event type is never published via ApplicationEventPublisher.publishEvent().

Spring events are weakly typed at the invocation site — the publisher and listener are connected only by the event class. When refactoring changes the event type or removes a listener, the connection silently breaks. This inspection cross-references all publishEvent() call sites against all @EventListener and @TransactionalEventListener parameter types to flag dead ends before they cause silent failures at runtime.
