Reports references that break a custom dependency rule from .spring-buddy/architecture.json (code SB-ARCH-001).

Each rule names the packages it constrains (from) and the packages they must not use (mustNotDependOn). Both accept layer names from layers or package patterns: com.acme.domain.. (package and subpackages), ..domain.., com.acme.*, or regex:.... except patterns exempt a target type or a source class.

A dependency is any resolved reference: imports (including wildcard imports), fully-qualified names, annotations, field, parameter, return and generic types, extends/implements, new and static calls. Unresolved types are never reported. Each forbidden type is reported once per file, at its import or otherwise at its first use. Test sources are skipped unless includeTests is true.

The severity comes from the rule (error, warning, weak_warning, off). ERROR findings block the Spring Buddy pre-commit check. Without a config file this inspection reports nothing. Fix the finding by moving the code to the right layer or by depending on an abstraction owned by the source layer, for example a port interface.

Example rule:

{ "id": "domain-no-web", "from": "domain", "mustNotDependOn": "web",
  "severity": "error", "message": "Domain must not know the web layer" }
