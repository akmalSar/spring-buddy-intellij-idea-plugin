Reports REST controller methods that return JPA entities (or collections of entities) containing lazy-loaded associations (@OneToMany, @ManyToOne, etc.) without @JsonIgnore or an explicit DTO projection.

Jackson serialization triggers proxy initialization outside of an active Hibernate session, causing LazyInitializationException in production. If the session is still open (e.g. Open Session in View), it causes N+1 queries that kill response times. Convert the return type to a DTO, or add @JsonIgnore to the association field.
