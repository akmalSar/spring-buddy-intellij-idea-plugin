Reports configuration properties that were renamed or removed in Spring Boot 4: spring.jackson.read.* → spring.jackson.json.read.*, spring.jackson.write.* → spring.jackson.json.write.*, the partially replaced spring.jackson.parser.*/spring.jackson.generator.*, spring.dao.exceptiontranslation.enabled → spring.persistence.exceptiontranslation.enabled, management.tracing.enabled → management.tracing.export.enabled and the removed spring.flyway.clean-on-validation-error.

Spring Boot 4 reorganises configuration namespaces while renaming removed properties; unknown keys are silently ignored, so a stale property can disable a feature without any error.

Quick fix renames the property (or deletes the removed Flyway property line). spring.jackson.parser.* and spring.jackson.generator.* have no fix: only features with a Jackson 3 JsonReadFeature/JsonWriteFeature equivalent move to spring.jackson.json.read/write; the rest need a JsonMapperBuilderCustomizer.
