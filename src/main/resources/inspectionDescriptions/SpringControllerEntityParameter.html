Controller endpoint accepts JPA entity

Reports parameters of request-mapped controller methods (@RequestMapping, @GetMapping, @PostMapping, ...) whose type is a JPA entity or contains one, such as List<User> (code SB-ARCH-003, preset controllerBoundary).

Binding request data straight into an entity lets clients set any mapped field (mass assignment), couples the API contract to the database schema, and tempts code to save a detached object built from the request. Bind a request DTO and map it to the entity in the service layer.

The severity follows the controllerBoundary preset of .spring-buddy/architecture.json (WARNING by default, error or off when configured).
