Reports references to org.springframework.boot.web.embedded.undertow.* such as UndertowServletWebServerFactory.

Spring Boot 4 dropped Undertow as a supported embedded server (React Web docs list only Reactor Netty, Tomcat and Jetty). Applications using Undertow must switch to another container.

No automatic fix: choose Tomcat or Jetty and remove Undertow-specific customizers and properties.
