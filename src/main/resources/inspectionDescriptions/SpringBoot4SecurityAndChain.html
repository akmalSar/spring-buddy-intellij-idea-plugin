Reports calls to and() on Spring Security configurers, removed from the HttpSecurity DSL in Spring Security 7 (Spring Boot 4).

Spring Security 7 removed and() in favour of the lambda DSL. Chained configurers such as http.authorizeRequests().and().formLogin() no longer compile.

Restructure the chain into nested lambda DSL calls, for example http.authorizeHttpRequests(customizer) followed by http.formLogin(customizer).
