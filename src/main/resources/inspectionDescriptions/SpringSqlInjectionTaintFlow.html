Reports potential SQL injection through intra-procedural taint flow: @RequestParam, @PathVariable, or request-object values that are concatenated into strings and passed to query execution methods such as JdbcTemplate.query, EntityManager.createNativeQuery, or Statement.execute.

Spring Data @Query annotations only accept compile-time constants, but dynamic queries built with string concatenation in service or controller methods are a direct SQL injection vector. Replace concatenation with parameterized queries (? placeholders or named parameters) or use JPA Criteria API.
