Reports SLF4J Logger calls (trace/debug/info/warn/error) whose first argument is built via String concatenation ("x=" + x). This includes the log field generated by Lombok's @Slf4j / @XSlf4j annotations.

Prefer the parameterized form "x={}", x, which lets SLF4J skip message formatting when the log level is disabled and produces consistent output.

A quick-fix is offered to flatten simple + chains into a placeholder message and pass non-literal operands as additional arguments.
