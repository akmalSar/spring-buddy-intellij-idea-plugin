Reports call sites where the result of an @Async method returning a Future/CompletableFuture/ListenableFuture is silently discarded as an expression statement.

When the returned future is ignored, exceptions thrown inside the async task are swallowed — no caller sees them. Either consume the future (chain thenApply/whenComplete, register a callback, or call get()), or change the method to return void.

For CompletableFuture / CompletionStage return types a quick-fix chains .exceptionally(...) with a log.error handler so failures are visible instead of silently dropped. For plain Future / ListenableFuture the quick-fix assigns the result to a local variable so the caller can handle it explicitly.
