Reports potential N+1 query problems detected by the DataFlow taint engine.

A collection of JPA entities is loaded from a Spring Data repository or EntityManager query, then iterated inside a loop or stream. On each iteration a lazy association getter is invoked, causing an extra SQL select per element.

Fix by eagerly fetching the association with a fetch join, @EntityGraph, @BatchSize, or a DTO projection that only selects the columns you need.
