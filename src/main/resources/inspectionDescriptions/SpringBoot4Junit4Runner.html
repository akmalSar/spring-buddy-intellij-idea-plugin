Reports @RunWith(SpringRunner.class) and SpringJUnit4ClassRunner, deprecated in Spring Framework 7 (Spring Boot 4) in favour of JUnit Jupiter.

Spring Framework 7 deprecates the JUnit 4 TestContext support. Existing JUnit 4 based Spring tests keep working for now, but should be migrated to @SpringBootTest with JUnit Jupiter.

Migrate the test class to JUnit Jupiter (org.junit.jupiter.api.Test); the JUnit Vintage engine can bridge the transition.
