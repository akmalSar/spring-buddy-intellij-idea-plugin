Reports @SuppressWarnings values and //noinspection comments that switch off a Spring Buddy architecture check (code SB-ARCH-007).

A suppressed architecture finding disappears from the editor, the pre-commit check and the Markdown export, but the violation stays in the code. Coding agents in particular tend to suppress a failing check instead of fixing the cause. This inspection reports every token that targets an architecture check: an inspection short name such as DomainPurity, BannedApi or ForbiddenPackageDependency, or a code such as SB-ARCH-004.

A suppression is accepted only when every rule or preset it hides has "allowSuppression": true in .spring-buddy/architecture.json (on a rule, a bannedApis entry, or a preset object). This inspection cannot be suppressed itself. Severity comes from the suppressionPolicy preset (WARNING by default, error to block commits, off to disable).

Fix: remove the suppression and fix the violation. For an intended exception, add it to the rule's except or the banned API's allowedIn, or accept existing violations with Tools | Spring Buddy Architecture | Generate / Refresh Architecture Baseline. 

"presets": { "suppressionPolicy": "error",
             "constructorInjection": { "severity": "warning", "allowSuppression": true } }
