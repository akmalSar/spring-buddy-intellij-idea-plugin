Reports Jackson types that were renamed between Jackson 2 and Jackson 3, such as JsonProcessingException → JacksonException, JsonSerializer → ValueSerializer, JsonDeserializer → ValueDeserializer, SerializerProvider → SerializationContext and JsonMappingException → DatabindException.

Spring Boot 4 upgrades to Jackson 3, so code extending or catching the old types must switch to the new names.

Quick fix replaces the type reference and import when the mapping is verified.
