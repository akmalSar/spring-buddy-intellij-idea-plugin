Reports Mockito when(mock.method(...)) / given(mock.method(...)) stubbings inside a @Test method whose stubbed method name is not invoked anywhere else in the test body.

Under strict stubbing (Mockito 3+) this would already fail; under lenient stubbing or with custom rules these dead stubs accumulate and obscure the real test intent.

Detection is name-based and conservative — only flagged when the stubbed method name literally does not appear elsewhere in the test method.

The quick-fix removes the unused stubbing statement.
