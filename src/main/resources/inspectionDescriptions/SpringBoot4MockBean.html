Reports @MockBean and @SpyBean usages, which were removed in Spring Boot 4.

Spring Framework 6.2 introduced @MockitoBean/@MockitoSpyBean as the supported way to override beans in tests. Spring Boot 4 removes the old org.springframework.boot.test.mock.mockito annotations entirely, so test code still using them no longer compiles or runs.

Replace usages with @MockitoBean / @MockitoSpyBean (quick fix available). The fix keeps name, reset and answer (as answers); class-level @MockBean(SomeClass.class) becomes @MockitoBean(types = SomeClass.class).
