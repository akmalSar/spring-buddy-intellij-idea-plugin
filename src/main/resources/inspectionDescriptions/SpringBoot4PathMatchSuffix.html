Reports calls to PathMatchConfigurer.setUseSuffixPatternMatch, setUseRegisteredSuffixPatternMatch and setUseTrailingSlashMatch, which were removed in Spring Framework 7 (Spring Boot 4).

Spring Framework 7 removed the deprecated suffix-pattern and trailing-slash matching APIs. Requests such as /users/foo.json and /users/ no longer match /users/{id}.

Quick fix deletes the removed call statement. Otherwise rely on the default parsed-pattern matching of PathPatternParser.
