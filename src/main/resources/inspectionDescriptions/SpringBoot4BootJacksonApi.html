Reports Spring Boot Jackson integration types that were renamed or relocated in Spring Boot 4: @JsonComponent/@JsonMixin → @JacksonComponent/@JacksonMixin, JsonComponentModule/JsonMixinModule → JacksonComponentModule/JacksonMixinModule, Jackson2ObjectMapperBuilderCustomizer → JsonMapperBuilderCustomizer and JsonObjectSerializer/JsonObjectDeserializer → ObjectValueSerializer/ObjectValueDeserializer.

Spring Boot 4 splits Jackson support into the spring-boot-jackson module and aligns its API with Jackson 3 naming.

Quick fix replaces the annotation or type with the new name and updates the import.
