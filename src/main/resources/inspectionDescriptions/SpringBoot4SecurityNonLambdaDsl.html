Reports zero-argument HttpSecurity configurer methods such as csrf(), formLogin() or authorizeHttpRequests(), removed in Spring Security 7 (Spring Boot 4).

Spring Security 7 only keeps the lambda DSL variants that take a Customizer argument, e.g. http.csrf((customizer) -> ...). The deprecated zero-arg overloads were removed.

For the unambiguous shape http.x().disable() a quick fix offers http.x((customizer) -> customizer.disable()). All other cases require manual conversion.
