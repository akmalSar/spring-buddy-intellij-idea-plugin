Reports controller methods that accept MultipartFile parameters without size limits (@Size, @Max) or explicit content-type validation.

An unrestricted file upload endpoint allows attackers to exhaust server disk space or storage quotas by uploading arbitrarily large or numerous files. Add @Max(10485760) (or @Size) to the parameter, validate file.getContentType() inside the method body, or configure spring.servlet.multipart.max-file-size in application properties.
