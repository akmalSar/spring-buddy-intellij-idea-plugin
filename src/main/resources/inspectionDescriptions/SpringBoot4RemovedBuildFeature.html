Reports build features removed in Spring Boot 4: embedded launch scripts (launchScript(), <executable>true</executable>), Spring Session Hazelcast and MongoDB, Spring Pulsar Reactive and Spock.

These integrations are no longer provided or managed by Spring Boot 4, so the build fails or the application misses the auto-configuration. Use java -jar with a service manager instead of launch scripts and take the dependency (and its version) from the respective project directly.
