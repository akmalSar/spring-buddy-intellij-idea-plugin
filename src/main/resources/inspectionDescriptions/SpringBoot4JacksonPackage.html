Reports imports and references of com.fasterxml.jackson.core.* and com.fasterxml.jackson.databind.* and com.fasterxml.jackson.dataformat.*, which moved to tools.jackson.* in Jackson 3 (default in Spring Boot 4), as well as Jackson 2 modules under com.fasterxml.jackson.datatype.*/com.fasterxml.jackson.module.*.

Jackson 3 renamed its root package from com.fasterxml.jackson to tools.jackson for core and databind. The annotations package com.fasterxml.jackson.annotation (@JsonIgnore, @JsonProperty, …) is unchanged.

Switch imports to tools.jackson.* (quick fix offered when the type name is unchanged). Module packages have no quick fix: java.time, Jdk8 and parameter-names support are built into Jackson 3 databind, so those module registrations can usually be removed. Jackson 2 support exists in the spring-boot-jackson2 module only as a migration aid and is deprecated.
