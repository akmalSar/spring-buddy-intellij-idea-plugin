Reports usages of AntPathRequestMatcher and MvcRequestMatcher, removed in Spring Security 7 (Spring Boot 4).

Spring Security 7 removes these matchers in favour of PathPatternRequestMatcher, which parses patterns up front and handles trailing slashes consistently.

Replace matchers with PathPatternRequestMatcher.withDefaults().matcher(...) or PathPatternRequestMatcher.withDefaultPathPatternParser(); builder semantics differ, so the migration is manual.
